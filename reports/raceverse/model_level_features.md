# RACEVERSE base / formation / pace の学習要素

## 対象

ここでの要素一覧は、各馬の相対走破性能を学習するモデルの入力特徴を示す。目的変数は「馬の走破時計 - 同レース出走馬の平均走破時計」で、値が大きいほど平均より遅い。各特徴量はレース内で中心化して使う。

## レベル別の特徴量

| レベル | 学習に使う特徴 | 意味 |
|---|---|---|
| base | `ability_c` | 既存Rankerの能力指標。出走馬間で中心化した能力差。 |
| formation | `ability_c`, `q_c`, `slot_c` | baseに、シミュレーションで抽選した序盤位置の相対値と、前後グループ内での内外位置を追加。 |
| pace | `ability_c`, `q_c`, `slot_c`, `q_x_pace`, `closing_x_pace` | formationに、序盤位置と連続値ペースの相互作用、および過去の上がり相対指標とペースの相互作用を追加。 |

## 特徴量の詳細

- `ability_c`: 既存Rankerの能力スコアをレース内で中心化した値。
- `q_c`: 抽選された序盤位置をレース内で中心化した値。
- `slot_c`: 前後グループ内での内外位置をレース内で中心化した値。
- `q_x_pace`: `q_c` と連続値ペース偏差の積。序盤位置とペース条件の相性を表す。
- `closing_x_pace`: 過去の上がり相対指標と連続値ペース偏差の積。差し・末脚傾向とペース条件の相性を表す。

ペース偏差は基準前半ラップとの差を秒で表し、負の値ほど基準より速いペース。馬ごとの200m区間ラップはDBにないため、上がり指標はペース適性そのものではなく代理指標である。

## 読み方の注意

- formation / paceで追加される序盤位置やペースは、固定値をそのまま予測に入れるのではなく、レースシミュレーションごとに抽選された値を使う。
- 各レベルで異なるのは走破性能モデルが平均予測に使う特徴量。隊列・ペースの生成やシミュレーション自体が、baseでは停止するという意味ではない。
- `closing_c`、`young_c`、`layoff_c`、`weight_c` は `full` レベルで追加される特徴であり、この一覧のbase / formation / paceには含まれない。
- 決着時計の予測モデルは別モデル。ここに記載した各馬の着順・勝率を決める走破性能モデルの特徴とは区別する。
