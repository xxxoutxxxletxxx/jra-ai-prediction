# AI本命と実際の1番人気が一致するケースの予測勝率閾値分析

## 結論

- 対象は12か月 walk-forwardデータ（2025-09-06〜2026-08-09、1,627レース）。
- 「AI本命（`prediction_rank == 1`）かつ実際の1番人気（`popularity == 1`）」は **912件**。
- 通常の1番人気全体（1,622件）と比べると、AI本命と一致した1番人気は的中率・複勝率が高い。
- ただし、30%以上〜50%以上の全閾値で単勝ROI・複勝ROIは100%未満だった。
- 閾値を上げるほど勝率・複勝率・6着以下率は概ね改善するが、45%以上・50%以上は件数が少なく、ROIはむしろ低下している。
- **現時点で「固い」と判定する閾値として最も妥当なのは35%以上**。
  - 181件あり、勝率48.62%、複勝率80.66%、6着以下率9.39%。
  - 前半6か月・後半6か月でも勝率はほぼ同水準（49.23% / 48.28%）。
- ただし、35%以上でも単勝ROI84.2%、複勝ROI90.4%であり、**単勝・複勝の無条件購入ルールとしては採用しない**。
- 40%以上は勝率52.58%、6着以下率9.28%で安全性は高いが、97件と減少し、複勝ROIは85.1%に低下する。安全性重視なら40%以上、件数と再現性のバランスなら35%以上が候補である。

## 集計方法

- 入力: `reports/ranker_walk_forward_12m/walk_forward_predictions.csv`
- 対象期間: 2025-09-06〜2026-08-09
- 一致条件: `prediction_rank == 1` かつ `popularity == 1`
- 閾値条件: `ranker_win_probability >= 閾値`（累積条件）
- 勝率: `target == 1` の割合
- 複勝率: `actual_rank <= 3` の割合
- 6着以下率: `actual_rank >= 6` の割合
- 単勝ROI: 単勝払戻合計 ÷（件数 × 100円）× 100
- 複勝ROI: DBの `PayFukusyo` 払戻合計 ÷（件数 × 100円）× 100
- 複勝払戻は1番人気馬の馬番をレース結果DBに紐付けて取得した。912件すべてで馬番が一致し、615件で複勝払戻が発生した。
- なお、閾値30%以上は「30〜35%」ではなく、予測勝率30%以上の全件を意味する。

### 読み取り

- 30%→35%→40%では勝率が42.02%→48.62%→52.58%と上昇する。
- 45%以上・50%以上では勝率が安定して上昇せず、少数サンプルの影響が大きい。
- 6着以下率は35%以上で9.39%、40%以上で9.28%まで低下する。
- 45%以上では6着以下率5.26%だが57件、50%以上では6.90%だが29件であり、強い再現性の根拠とはしにくい。
- ROIは閾値を上げても100%に届かない。予測勝率が高い1番人気ほどオッズが低くなるため、的中率向上と回収率向上は一致していない。

## 閾値の妥当性

### 30%以上

- 307件で十分な件数。
- 勝率42.02%、6着以下率13.03%。
- ただし、35%以上と比べると安全性が劣る。
- 「固い」判定の最低ラインとしてはやや緩い。

### 35%以上（第一候補）

- 181件で、サンプル数と安全性のバランスが最も良い。
- 勝率48.62%、複勝率80.66%、6着以下率9.39%。
- 前半・後半の勝率がほぼ同じ。
- ただし、ROI100%超ではないため、購入可否はオッズや別の期待値条件と併用する必要がある。

### 40%以上（安全性重視の候補）

- 勝率52.58%、6着以下率9.28%。
- 35%以上より件数が半減する。
- 複勝率・複勝ROIは35%以上を上回らず、明確な優位性はない。
- 本数を減らしてでも高勝率を優先する場合の候補。

### 45%以上・50%以上

- 6着以下率は低いが、57件・29件と少ない。
- 単勝ROIは75.4%・72.4%で、購入条件としては改善していない。
- 現時点で本番閾値に採用する根拠は不足している。

## 最終評価（実装前の候補）

1. **判定閾値の第一候補: AI予測勝率35%以上**
   - 1番人気との一致を前提に「固い」と判定する基準として、件数・勝率・期間再現性のバランスが最良。
2. **安全性優先の代替候補: 40%以上**
   - 6着以下率をおおむね9%まで抑えられるが、サンプル数が少なくなる。
3. **購入ルールとしては別途制限が必要**
   - 35%以上でも単勝ROI84.2%、複勝ROI90.4%のため、35%以上だけで無条件購入しない。
   - オッズ上限、期待値、レース条件などを組み合わせた追加検証が必要。

今回の分析では本番ロジック・購入ロジックを変更していない。
